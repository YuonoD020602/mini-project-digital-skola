# Mini Project Digital Skola

Kumpulan mini project bootcamp AI Engineer Digital Skola.

## Mini Project 2 — News & HR Analytics API
Folder: `mini-project-2`

API berbasis FastAPI dan PostgreSQL dengan endpoint:
- `GET /articles/search` — pencarian artikel dengan filter dan pagination
- `GET /articles/stats` — statistik jumlah artikel per sumber
- `GET /attrition/department/{dept_name}` — statistik attrition per departemen
- `GET /attrition/risk-profile` — profil karyawan berisiko tinggi

Autentikasi memakai API key dan JWT Bearer token.
